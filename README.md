# EcoSync + Avatar Lumi

Plataforma de engajamento sustentavel com gamificacao e avatar inteligente, desenvolvida para o Challenge 2026 - Sprint 1.

## Sobre o Projeto

O EcoSync e uma solucao inovadora que utiliza gamificacao para engajar colaboradores e usuarios em acoes sustentaveis. Atraves do Avatar Lumi, cada acao sustentavel e convertida em XP verde, criando uma experiencia visual e emocional de recompensa.

### Funcionalidades Principais

- **Avatar Lumi**: Avatar evolutivo que reage as escolhas sustentaveis do usuario
- **Calculadora de CO2**: Calculo em tempo real de economia de carbono
- **Sistema de XP**: Gamificacao com niveis, streaks e recompensas
- **Rankings**: Competicao saudavel entre equipes e colaboradores
- **Assistente Watson**: Suporte conversacional com IA

## Tecnologias Utilizadas

- **HTML5**: Estrutura semantica e acessivel
- **CSS3**: Estilizacao com variaveis, Grid, Flexbox e animacoes
- **JavaScript**: Interatividade, validacao de formularios e manipulacao do DOM
